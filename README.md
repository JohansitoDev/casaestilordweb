# CasaEstiloRD — landing promocional

Landing page responsive creada con Astro para promocionar la aplicación móvil CasaEstiloRD en República Dominicana.

## Requisitos
- Node.js 20.3.0 o superior
- npm

## Ejecutar
```bash
npm install
npm run dev
```
Abre la dirección que muestra Astro (normalmente http://localhost:4321).

## Compilar
```bash
npm run build
npm run preview
```

## Personalización
- Edita `src/pages/index.astro` para cambiar textos, productos, categorías y enlaces.
- Cambia los enlaces de descarga en `src/pages/index.astro` (Google Play / App Store).
- Los productos de demostración usan ilustraciones CSS y emojis; reemplázalos por fotografías reales cuando tengas tu catálogo.
- El proyecto no necesita React ni dependencias adicionales.

## Nota
Los enlaces de descarga son marcadores de posición. Sustitúyelos por los enlaces oficiales de tu aplicación antes de publicar.
